# Элегант

Учебный веб-интерфейс барбершопа, выполненный в рамках курсового проекта.  
Сайт показывает услуги, мастеров, галерею, контактную информацию и форму имитации записи.

## Назначение проекта

Проект представляет собой клиентскую часть сайта барбершопа.  
Он работает как цифровая витрина: посетитель может посмотреть услуги, выбрать мастера, узнать стоимость и заполнить форму записи.

Проект не использует сервер, базу данных и сложные фреймворки. Вся логика выполняется в браузере с помощью HTML, CSS и JavaScript.

## Основные возможности

- главная секция с кратким описанием барбершопа;
- блок преимуществ;
- вывод карточек услуг из массива данных;
- фильтрация услуг по категориям;
- поиск услуги по названию;
- вывод сообщения, если услуга не найдена;
- вывод карточек мастеров;
- галерея работ;
- форма имитации записи;
- проверка обязательных полей формы;
- сообщения об ошибке и успешной записи;
- сохранение последней записи в `localStorage`;
- удаление сохранённой записи;
- переключение светлой и тёмной темы;
- адаптивная вёрстка для компьютера, планшета и телефона.

## Технологии

- HTML5;
- CSS3;
- JavaScript;
- `localStorage`;
- адаптивная вёрстка через медиазапросы.

Фреймворки, серверные языки и базы данных в проекте не используются.

## Описание файлов

`index.html`  
Содержит основную HTML-структуру сайта: шапку, навигацию, главный экран, услуги, мастеров, галерею, форму записи, контакты и подвал.

`css/style.css`  
Отвечает за внешний вид сайта, цвета, сетки, карточки, форму, адаптивность и светлую тему.

`js/data.js`  
Содержит массивы данных с услугами и мастерами. Эти данные используются для создания карточек на странице.

`js/script.js`  
Содержит основную JavaScript-логику: вывод карточек, фильтрацию, поиск, выбор услуги или мастера, проверку формы, сохранение записи и переключение темы.

`images/`  
Папка с изображениями для главного экрана, карточек, мастеров и галереи.

Достаточно открыть файл:

```text
index.html
```

в современном браузере.

## Форма записи

Форма содержит поля:

- имя клиента;
- телефон;
- услуга;
- мастер;
- дата;
- время.

Обязательные поля:

- имя;
- телефон;
- услуга;
- дата;
- время.

Поле мастера не является обязательным, потому что пользователь может записаться без выбора конкретного мастера.

При ошибке незаполненные поля выделяются красной рамкой.  
Если пользователь начинает редактировать поле, ошибка убирается только с этого поля.  
Текст ошибки исчезает только тогда, когда заполнены все обязательные поля.

После успешной проверки запись сохраняется в `localStorage` под ключом:

```text
barber-appointment
```

Тема сайта сохраняется под ключом:

```text
barber-theme
```

## Адаптивность

Сайт адаптирован под разные размеры экрана.

На широком экране:

- карточки услуг и мастеров выводятся в несколько колонок;
- блоки формы и контактов расположены в две колонки;
- навигация отображается в шапке.

На экранах до `900px`:

- появляется кнопка мобильного меню;
- основные двухколоночные блоки становятся одноколоночными;
- карточки выводятся по две в ряд;
- фильтры и поиск становятся друг под другом.

На экранах до `600px`:

- сетки карточек переходят в один столбец;
- форма становится одноколоночной;
- уменьшаются вертикальные отступы;
- подвал выравнивается по центру.
